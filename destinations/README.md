# Destination Research

Per-island research for the Paros bachelor-party trip (6 people, from Athens,
**Fri 17 → Sun 19 July 2026**, 2 nights). Brief: 4–5h from Athens, bars-but-not-clubs,
one house for all 6 (~2 per room), one affordable private skipper day, €2,000–3,000 all-in.

**Fit ranking:** Paros → Milos → Sifnos → Koufonisia → Naxos.

Each file now includes **3 vetted accommodation picks (3BR / sleeps 6)** across price tiers, with links,
how they were found, and cost estimates. Live exact-date (17–19 July 2026) prices need a manual search
on each platform — the booking sites block automated quotes.
