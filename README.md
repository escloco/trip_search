# trip_search

Accommodation research for a 6-person trip to the Cyclades, **Fri 17 → Sun 19 July 2026** (2 nights, everyone together).

**🌐 Live site:** https://escloco.github.io/trip_search/

A single-page browser of 13 real listings across 4 islands (Paros, Milos, Sifnos, Koufonisia),
each with a live price quote pulled for our exact dates and the property's own photo.

## What's here
- **`index.html`** — the listings page (hosted via GitHub Pages; auto-updates on every push to `main`).
- **`destinations/<island>/notes.md`** — per-island research notes with layouts, beds, and dated quotes.
- **`images/`** — each listing's own photo, downloaded by `download_images.js`.
- **`PLAN.md`** — full itinerary, budget, and booking logistics.

> Prices are live quotes for 17–19 July 2026, not estimates. Rates and availability can still change,
> so reconfirm on each listing before booking.
